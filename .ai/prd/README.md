# PRD 文档索引

更新时间：2026-06-08

`prd/` 只存放需求来源和验收目标，不承载具体实现方案。

## 版本主线

- `需求_v1.md`：AI 导购系统总体产品定位，定义移动端、后端、管理与测评后台的初始范围。
- `需求_v2.md`：补充质量测评、购物车/下单工具闭环、多模态和 RAG 上下文能力。
- `需求_v3.md`：明确用户端技术栈迁移到 Android 原生，React Web 用户端不再作为主用户端。
- `后端需求_v3.md`：后端业务域补全，包括会话、订单、优惠、评价和 tools。
- `后端需求_v4.md`：Prompt 和 Agent 主链路的新要求。
- `质量体系需求_v1.md`：测评数据、测评接口和报告要求。
- `prompt需求_v1.md`：意图分类和 Prompt 范式要求。
- `多轮记忆需求_v1.md`：短期上下文和会话摘要需求。

## 维护规则

1. 新比赛要求或产品目标先进入 `prd/`。
2. 具体实现方案写入 `tech/`。
3. 接口字段和协议写入 `api/`。
4. 已被后续版本替代的需求不删除，在 README 中说明当前状态。
