现在的安卓 APP 已经趋于稳定，因此你后面再新增功能的时候，尽量不要动已有功能。

1. 聊天页面
  - 现在的聊天页面左下角的 “+” 按钮点开之后，有 “相册” 和 “文件” 两个功能，请你在前面再加一个 “拍照” 功能
    - 点击 “拍照” 按钮之后，调用系统摄像头进行拍照，拍照后自动选取对应图片
  - 现在的 APP 在讯飞 API 的支持下，已经可以实现语音转文字了，我现在还想新增一个 TTS 的功能
    - 聊天页面的右上角放一个喇叭图标，用于控制 TTS 功能的开关
    - 当 TTS 功能开启的时候，自动朗读 AI 回复的内容
      - 朗读内容只包括正文内容
      - 朗读内容需要剔除 markdown 格式符号
      - 思考内容不需要朗读
    - 现在有两个方案供你选择
      - 端到端实时语音大模型：https://www.volcengine.com/docs/6561/1594356?lang=zh
      - 语音合成大模型：https://www.volcengine.com/docs/6561/1329505?lang=zh
      - 分析一下哪个适合我们的项目，看看里面需要配置什么，在 nacos 里配置一下，我后面在 nacos 里提供 API Key
