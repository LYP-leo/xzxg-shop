## 安卓 APP 问题总结文档 v1

这个文档用于总结安卓 APP 的问题
v1 主要解决 UI 设计与美化的问题

1. UI 设计部分

  - 主页
    - 主页左上角的侧栏按钮不要设置按钮背景
    - 主页下面的 “+”、“对话框”、语音输入的按钮高度不同且没有对齐，请你严格参考 /Users/leo/xzxg-shop/.ai/tech/assets/main.jpeg 这个主页下面进行设计。
    - 主页右上角应当可以点击，点击之后直接进入用户页面

  - 侧栏：你需要重新设计，严格参考 `/Users/leo/xzxg-shop/.ai/tech/assets/side-new.jpg` 这个页面
    - 最顶部左侧放置一个搜索栏，右侧放置一个创建新会话的按钮
    - 搜索栏下面放 “AI导购”、“商品”、“购物车”、“订单” 这四个页面按钮
      - 默认是在 “AI导购” 页面
      - 当前在哪个页面（图中是在 “AI导购” 页面），这个按钮的背景就是浅灰色的，其余按钮背景保持白色
      - 当我点击了 “商品” 按钮之后，切换到商品页面，点击侧栏之后，侧栏里商品按钮的背景就换成浅灰色
      - 每个按钮最左侧请你放置图标，例如 “AI导购” 左边要放个 AI 的图标、“商品” 左边要放个符合商品语义的图标、......
    - 再下面的 “历史聊天” 部分，下面的导购会话同样不要设置按钮背景，直接纯色即可
      - 有多少个历史聊天，就展示多少个历史聊天
        - 例如我刚进入 APP，就没有历史聊天
        - 我创建了新的聊天，历史聊天当中应当出现我上一个聊天
      - 历史会话记录如果过多，这个页面应当支持滚动，而不是固定的几个按钮
      - 历史聊天部分应当悬浮一个按钮，用于返回当前会话，对应你原来的 “聊天” 按钮
    - 最下方
      - 左侧展示用户头像和用户名，点击用户头像或者用户名都可以进入用户管理页面
      - 右侧只需要放一个 “设置” 按钮，点击后进入设置页面

  - 其他页面
    - “商品”、“购物车”、“订单”、“我的” 这些页面，顶部的标题（商品 / 购物车 / 订单）和页面介绍部分 与 侧栏按钮 靠得太近了

2. 动画

  - 点击侧栏按钮的时候，应当设计一个从左往右推出的动画，而不是直接显示
    - 侧栏推出的时候，原有页面应当变暗
  - 侧栏消失的时候，也应当设计一个从右往左收回的动画，而不是直接消失

3. 当我反复点击一个按钮的时候，会弹出很多次 “小猪小狗导购：xxxxxx”
  - 例如，在 “我的” 页面，反复点击 “保存测试地址” 按钮，会弹出很多次 “小猪小狗导购：已保存测试后端地址” 的弹窗，参考 `/Users/leo/xzxg-shop/.ai/tech/assets/bug_01.jpg`
  - 这个时候如果有新的弹窗出现，只能等弹窗弹完了才能显示
  - 正确处理方法是新的弹窗应当覆盖旧的弹窗，而不是等上一个弹窗弹完了再出现
