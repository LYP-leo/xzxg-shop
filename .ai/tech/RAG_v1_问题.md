## RAG_v1_问题

针对 `/Users/leo/xzxg-shop/.ai/tech/RAG设计_v1.md` 文档提出的问题与修改方向。

1. RAG 的知识库除了商家商品库，还包括**自建知识库**，例如去爬一些小红书、B 站的种草、介绍帖子
2. 获取了这些知识（可能是结构化的，也可能是非结构化的）之后，你需要经过切分、清洗等步骤（你在文档中已经提到了），然后存到向量数据库里
3. 关于图片该如何存储的问题
  + 我之前已经说过了尽量不要用 OCR，你可以使用图像语义理解大模型，将图片向量化后直接存到向量数据库里
  + 当用户上传了一张图片，要查找类似商品的时候，就可以根据图片向量去向量数据库里面查找类似的图片，从而找到对应的商品
4. Query 改写这部分不是由 RAG 模块负责的，交给向量数据库的就是已经改写好的，结构化的查询。

总而言之，你需要重新仔细阅读一下已有的代码和已有的文档，你的 RAG 模块要和已有工作耦合。
