1. 卡片信息的渲染与显示
  - 当我从历史记录里面返回聊天页面的时候，推荐的商品卡片和下面的提示词语（在对话框下面的深灰色小字，例如：“您还可以继续追问xxx” 等提示）会消失。
  - 当前的渲染功能依旧不是很好，有一些标签你还是没有成功渲染，例如开头的 <tool_call> </tool_call>。
    - 请你仔细参考 Web 端的聊天是怎么做的，把 Web 端实现的功能全部迁移到 Android 端。

2. 商品页面
  - 筛选器设计得并不合理，你应该设计多级菜单。
    - 参考已有电商APP去做，一级菜单可以先放一个商品类别。
    - 点击一级菜单里的 “商品类别” 之后，再在新的窗口中选择商品类别。
  - 查看详情之后再返回，会直接回到页面顶端，而不是返回到我进入 “商品详情” 页面之前浏览的位置。
  - 商品详情里面，如果有栏目（比如：推荐理由）里面的内容过长，你应该设计一个 “显示更多” 的无边框按钮，点击之后拉长这个条目，继续把剩余内容全都展示出来。
