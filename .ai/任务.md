# 要求
这个仓库将用于参加一个比赛，要求是：

基于 iOS/Android 原生框架、Node.js/Python/Go 等后端服务、向量数据库及大模型 OpenAPI 等技术栈，构建一个打通"意图理解-智能咨询-决策辅助"核心路径的电商 AI 导购系统。 要求实现一个能够深度理解商品属性、用户意图并提供个性化决策支持的智能 Agent。通过上传非结构化的商品详情与营销文档构建专属知识库，系统通过 RAG 技术确保回复的专业性与准确性；在客户端，需利用原生技术栈打造媲美"豆包"的流式交互体验，同时支持商品卡片实时渲染、多模态（文字/图片）输入解析。 同时，课题需构建一套端到端的质量评测与反馈闭环，通过对典型导购场景下的回答准确率、知识检索精度及多轮对话逻辑进行定量评估，反哺 Prompt 策略优化与知识库迭代，旨在验证该工程方案在模拟商业场景下的技术可行性与交互质量，并为电商导购从"信息搜索"向"辅助决策"的代际跨越提供工程实践参考。

比赛官网：https://bytedance.aiforce.cloud/app/app_4k10u9vy4dz50/ai-challenge

.ai文件夹是所有我们的约定和文档文件夹，用于spec coding。
- Prd文件夹：存放需求文档
- tech文件夹：存放技术方案
- pics文件夹：存放图片
