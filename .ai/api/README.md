# API 文档索引

更新时间：2026-06-08

本目录保存前后端、Android 客户端和 Agent runtime 的接口契约。

## 版本说明

- `API接口文档_v1.md`：项目最早期接口基线，覆盖认证、商品、购物车、订单和基础 Agent 对话。用于理解接口从普通电商 CRUD 到 Agent 化的起点。
- `API接口文档_v2.md`：加入三端角色、分页、质量测评、链路追踪、配置中心和更完整的电商业务域。用于理解中期后台和生产化能力如何补齐。
- `API接口文档_v3.md`：当前联调基线。新增或修改接口应优先更新此文件。
- `Agent输出协议_v1.md`：Agent SSE 与结构化输出协议。它虽然不是普通 REST API，但属于前后端强契约，因此放在 `api/` 下。

## 维护规则

1. 新接口必须写清：权限、请求体、query 参数、响应体、错误码。
2. 列表接口默认分页，并写明 `page`、`page_size`、`total`。
3. Agent 输出协议变更必须同步 Android 客户端解析约定。
4. 如果接口已废弃，不要直接删除历史版本，在当前版本中标记“废弃/迁移到”。
5. 涉及密钥、Prompt、trace、LLM 原始输入输出的接口必须写明脱敏策略。
