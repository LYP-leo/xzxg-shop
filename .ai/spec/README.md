# Spec 文档索引

更新时间：2026-06-08

`spec/` 放跨模块、长期稳定的项目规范和系统说明。它和 `tech/` 的区别是：

- `tech/` 记录某个功能怎么设计、怎么落地，允许随版本快速变化。
- `spec/` 记录项目当前约定、分层、编码规则、答辩表达和长期稳定的协作规范。

## 当前文档

- `编码规范_v1.md`：仓库编码与目录规范。
- `系统分层与职责_v1.md`：系统架构分层、每层职责和技术栈。
- `文档体系规范_v1.md`：`.ai` 文档目录和版本管理规则。
- `business/项目亮点与方案梳理_v1.md`：答辩和技术文档可复用的项目亮点材料。
